ABSTRACT
Disaggregated LLM inference executes the prefill and decode phases on sepa-
rate resource pools, reducing interference between the two phases. However, this
architecture introduces a coupled scheduling problem because a request that com-
pletes prefill retains its prompt KV cache in prefill memory until it is admitted to
the decode pool. Prefill and decode admission decisions therefore jointly deter-
mine memory occupancy and request completion times. To the best of our knowl-
edge, this problem lacks a formal formulation, and no approximation guarantees
are known for request scheduling in disaggregated LLM inference. We formal-
ize this setting as the dual-memory request scheduling (DMRS) problem, whose
objective is to minimize the sum of request completion times, and prove that it is
strongly NP-hard. We develop two deterministic polynomial-time approximation
algorithms. The first applies to instances satisfying α<1 and β <1 and achieves
an approximation ratio of 8+ 4

1−β, where αand βare the maximum normal-
ized prefill and peak decode memory demands among all requests, respectively. In
particular, it yields a 32-approximation when α,β ≤1/2. The second algorithm
applies to all feasible instances and achieves a uniform 36-approximation. Finally,
evaluations on two H100 GPUs using trace-derived offline workloads show that
the proposed algorithms reduce the sum of request completion times relative to
multiple vLLM deployment baselines.
1 INTRODUCTION
Large language model (LLM) inference consists of a prefill phase followed by an autoregressive
decode phase. During prefill, the model processes the prompt tokens in parallel and constructs
the key-value (KV) cache. During decoding, output tokens are generated sequentially, and the KV
cache expands with each token. Prefill is generally compute-bound, whereas decoding is more
sensitive to memory bandwidth and KV cache capacity (Patel et al., 2024; Zhong et al., 2024).
When colocated on the same GPUs, the two phases compete for shared resources. To reduce this
interference, recent systems execute the prefill and decode phases on separate GPU instances or
resource pools (Patel et al., 2024; Zhong et al., 2024; Hu et al., 2024b; Qin et al., 2026; Jiang et al.,
2025). This architecture allows resources to be allocated independently to the two phases.
However, prefill-decode disaggregation does not eliminate the scheduling dependence between the
two phases. After completing prefill, a request may be unable to enter decoding immediately if the
available decode memory is insufficient. While waiting, the request retains its prompt KV cache
in prefill memory, prolonging its occupancy of that memory and potentially blocking subsequent
prefill admissions. Upon decode admission, the KV cache is transferred to decode memory, and
the retained prefill memory is released. The request’s decode memory usage then grows as output
tokens are generated. Consequently, prefill and decode admission decisions are coupled through
their effects on memory occupancy in the two resource pools.
Existing systems work has investigated serving architectures and resource allocation (Zhong et al.,
2024; Patel et al., 2024; Hu et al., 2024b; Jiang et al., 2025), request scheduling and load balancing
to improve goodput and meet service-level objectives (Wang et al., 2025a; Wu et al., 2025; Jin et al.,
2024), and KV cache transfer, storage, and management (Qin et al., 2026; Hu et al., 2024a; Luo

2 SYSTEM MODEL AND FORMULATION
In this section, we first present the system model. We then formulate DMRS, establish its com-
putational complexity, and derive an LP relaxation for our approximation analysis. Appendix A
summarizes the notation used throughout the paper.
2.1 SYSTEM MODEL
In our model, the prefill and decode phases execute on separate resource pools with respective
memory capacities MP,MD ∈Z>0.
Execution Setup. Time is divided into slots [t,t+ 1), where t∈{0,1,2,...}. KV cache memory
is measured in token units, with one unit representing the memory required to store the key and
value states of one token. During prefill, each active request processes its prompt for a fixed number
of slots. During decoding, each active request completes one decode iteration and generates one
output token per slot. Multiple requests may execute concurrently in each phase, subject to the
corresponding memory capacity. Execution is non-preemptive within each phase: once admitted to
a phase, a request remains active until it completes that phase.
Inference Requests. Let I= {1,...,n}denote the set of requests. Each request i∈Iis charac-
terized by (mi,pi,di) ∈Z3
>0, where mi is its effective prefill processing time, measured in advance
under the given deployment configuration and expressed in slots; pi is the number of input tokens
in its prompt and, equivalently, its prefill memory demand in token units; and di is the number of
output tokens to be generated and, equivalently, the number of decode iterations. After generating
uoutput tokens, request ihas decode memory demand ri(u) = pi + u. Its peak decode memory
demand is hi = ri(di) = pi + di.
Throughout the paper, we assume that pi ≤MP and hi ≤MD for every i ∈I. These conditions
are necessary and sufficient for feasibility, since the requests can always be processed sequentially.
Let α := maxi∈Ipi/MP and β := maxi∈Ihi/MD denote the maximum normalized prefill and
peak decode memory demands, respectively. The feasibility conditions imply α,β ≤1.

6 RELATED WORK
LLM Inference Serving and KV Cache Management. Orca (Yu et al., 2022) introduces
iteration-level scheduling, vLLM (Kwon et al., 2023) manages KV caches with PagedAttention,
and Sarathi (Agrawal et al., 2023) uses chunked prefills. FastServe (Wu et al., 2023) uses pre-
emptive scheduling, AlpaServe (Li et al., 2023) multiplexes models through model parallelism, and
FlexGen (Sheng et al., 2023) offloads model state. DeepSpeed-Inference (Aminabadi et al., 2022)
optimizes parallel execution, while DeepSpeed-FastGen (Holmes et al., 2024) uses Dynamic Split-
Fuse. SGLang (Zheng et al., 2024), Preble (Srivatsa et al., 2025), and CacheGen (Liu et al., 2024)
address prefix reuse, distributed scheduling, and KV cache compression and streaming, respectively.
These systems do not model joint admission under separate prefill and decode memory capacities.
Prefill-Decode Disaggregated Serving. Splitwise (Patel et al., 2024) separately provisions pre-
fill and decoding, DistServe (Zhong et al., 2024) optimizes phase-specific parallelism, and Tetri-
Infer (Hu et al., 2024b) combines disaggregation with prompt chunking. Mooncake (Qin et al.,
2026) and MemServe (Hu et al., 2024a) provide disaggregated KV cache storage and reuse; Smart-
Gen (Luo et al., 2026) studies selective cache transfer, and HexGen-2 (Jiang et al., 2025) targets
heterogeneous resources. TaiChi (Wang et al., 2025a), Arrow (Wu et al., 2025), and P/D-Serve (Jin
et al., 2024) adapt serving decisions to workloads and system conditions. These works do not pro-
vide approximation guarantees for joint admission scheduling.
Theoretical Scheduling Models. Jaillet et al. (2025) and Ao et al. (2025) study online scheduling
under a unified memory constraint, while Wang et al. (2025b) consider heterogeneous prefill and
decode lengths under a shared cache capacity. Feng et al. (2026b) derive competitive and constant-
factor approximation guarantees for non-clairvoyant and clairvoyant scheduling, respectively, under
a single KV cache capacity. Their subsequent work develops a general non-clairvoyant schedul-
ing framework (Feng et al., 2026a). Chen et al. (2025) consider uncertain output lengths. Bari
et al. (2025) study routing and throughput-oriented scheduling, while Dai et al. (2025) analyze the
throughput optimality of work-conserving scheduling. These models do not capture retained prompt
caches across separate prefill and decode memory pools.
7 CONCLUSION AND FUTURE WORK
We formulated DMRS for disaggregated LLM inference, jointly scheduling prefill and decode ad-
missions under separate memory capacities while accounting for prompt KV caches retained in
prefill memory and growing decode KV caches. We proved strong NP-hardness, derived an LP
lower bound, and developed two deterministic polynomial-time approximation algorithms. The first
achieves an approximation ratio of 8+ 4
1−α+ 8
1−β for α,β <1, while the second provides a uniform
36-approximation for every feasible instance, including instances with α= 1 or β = 1.
The CPU experiments show that both algorithms perform well relative to exact ILP solutions and LP
lower bounds. Experiments on two H100 GPUs show that both algorithms reduce total completion
time (TCT) relative to vLLM P/D across all tested settings on code workloads.
Limitations. We assume that output token counts are known in advance, consistent with the theo-
retical settings studied by Wang et al. (2025b) and Jaillet et al. (2025). This assumption allows us
to focus on the coupling between prefill and decode admissions under separate memory capacities.
The theoretical model assumes instantaneous KV transfer, whereas the completion times measured
in our GPU experiments include KV transfer overhead.
Future Work. We can extend DMRS in three directions. An online setting could address requests
arriving over time and establish competitive guarantees. A non-clairvoyant setting could remove
the assumption that output lengths are known in advance. A deadline-constrained setting could
maximize the total weight of requests completed by their deadlines.
